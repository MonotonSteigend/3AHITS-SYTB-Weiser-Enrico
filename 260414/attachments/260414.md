# command substitution
Befehle köennen mit hilfe von ``$(<cmd>)`` ausgeführt werden, und ihre Ausgabe kann dann im script weiter verarbeitet werden.

### Übung (Anzahl Einträge in einem Verzeichnis)

Recherche: https://www.geeksforgeeks.org/linux-unix/wc-command-linux-examples/

``count_files.sh``
```sh
r=$(ls -l "$1" | wc -l)
echo "Es sind $((r-1)) Einträge im dir $1"
```
die ausgabe von ls -l VERZEICHNIS gibt ``alle`` einträge in einem Verzeichnis zurück. Wenn man dass dann an wc -l (-lines) mittels einer pipe weitergibt bekommt man die Anzah der Zeilen

Am ende macht man ``r-1``, da ein Eintrag eine Systemnachricht ist.

``Ausführung: ``
```sh
rici@envy-u:~/HTL/3AHITS/Syt-B/.../260414/scripts$ ./count_files.sh ~/HTL/

Es sind 2 Einträge in dir /home/rici/HTL/
```


### Übung (Tage bis zum Ball)

Recherche: https://www.man7.org/linux/man-pages/man1/date.1.html

``tage_zum_ball.sh``
```sh                           
ball_date="2027-01-16"


ball_seconds=$(date -d "$ball_date" +%s)
curr_seconds=$(date +%s)

diff_tage=$(( (ball_seconds - curr_seconds) / 86400 ))

echo "Es sind noch $diff_tage Tage bis zum HTL Ball ($ball_date)"

```
- ``%s``: seconds since the Epoch
- ``-d``: Die date Befehler werden nicht mit dem jetzigen datum sondern einem angegebenem Datum ausgeführt



``Ausführung: ``
```sh 
rici@envy-u:~/HTL/3AHITS/Syt-B/.../260414/scripts$ ./tage_zum_ball.sh 

Es sind noch 276 Tage bis zum HTL Ball (2027-01-16)
rici@envy-u:~/HTL/3AHITS/.../260414/scripts$ 

```
