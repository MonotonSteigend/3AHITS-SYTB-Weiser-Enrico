## Werkstatt Summe
Recherche: https://www.geeksforgeeks.org/linux-unix/cut-command-linux-examples/


https://www.geeksforgeeks.org/linux-unix/paste-command-in-linux-with-examples/

https://www.geeksforgeeks.org/linux-unix/bc-command-linux-examples/

``werkstatt_summe.sh``
```sh
a=$(cat klassenkassa.csv | grep "Werkstatt" | cut -d "," -f 3 | paste -s -d+ |bc
echo $a
```
- cut -d legt dem delimiter fest
- cut -f bestimmt das feld das wir wollen in dem Fall das 3. 
- paste -s: sagt dem programm es soll alle Zeilen aus einer Datei nehmen und sie in eine Zeile schreiben.
- paste -d+: legt fest das nach jeder gelesenen Zeile ein + eingefügt wird in die Ergebnis-Zeile

``Ausführung: ``
```sh
rici@envy-u:~/scripts$ ./werkstatt_summe.sh 
411.09
rici@envy-u:~/scripts$ 
```

## Zeitmessung
Recherche: https://www.man7.org/linux/man-pages/man1/date.1.html


``time_start.sh``
```sh
date +%s > /tmp/start_time
```
``time_stop.sh``
```sh
start_time=$(cat /tmp/start_time)
stop_time=$(date +%s)
echo $((stop_time - start_time))

```

``Ausführung:``
```sh 
rici@envy-u:~/scripts$ ./start_time.sh 
rici@envy-u:~/scripts$ ./stop_time.sh 
5
rici@envy-u:~/scripts$ 
```

## Random

``random.sh:``

```sh
echo $(( ($RANDOM%($2-$1))+$1 ))

```

``Ausführung: ``

