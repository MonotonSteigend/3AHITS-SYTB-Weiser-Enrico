## Mitschrift

[schleifen.sh](/scripts/schleifen.sh)
```sh

#!/bin/bash
 
# while
counter=1
#while [ $counter -le 10 ] # <= 10
while ((counter <= 10))
do
    echo $counter
    ((counter++))
done
 
# for
 
echo "--- for ---"
# Liste = durch white-spaces getrennter string
data="1 2 3 4 5 6 7"
for d in $data
do
    echo $d
done
 
 
echo "--- Kommandozeilenargumente ---"
for arg in $@
do
    echo $arg
done
 
# brace expamsion {]
for value in {20..25}
do
    echo $value
done
 
 
echo "--- field seperator ---"
mylist="hallo welt,hello world,guten tag;ni hao"
IFS=",;" #internal field separator
for el in $mylist
do
    echo $el
done

```

### While
- mit dem Test Kommando ``while [ $counter -le 10 ] # <= 10``
- mit bash Arithmetik ``while ((counter <= 10))
``

### For 
Ein Datensatz ``data="1 2 3 4 5 6 7"``, wird mit ``for d in $data`` durchlaufen wobei `d` die Laufvariable ist. 


### Brace Expansion
mit ``for value in {20..25}`` wird von eine Liste mit den Werten von 20 bis 25 durchgelaufen wobei ``values`` die Laufvariable ist.

- Mit variablen kann man keine Brace Expansion machen (https://stackoverflow.com/questions/19432753/brace-expansion-with-variable)


### Field seperator
Der Field seperator ist eine variable ``IFS`` (internal field seperator), mit dem bestimmt wird nach was die datensätze wie ``values``, oder ``data`` getrennt werden
- Default: ``" "`` (Leerzeichen)

## Übung (Min)
Schreibe ein bash Skript das den Namen einer Datei als Argument akzeptiert:

``$ ./min.sh input.txt``

Die Input Datei enthält positive Zahlen die durch white spaces getrennt sind:

```
42
21 57
68 33 1
1
```


Das Skript soll die kleinste Zahl ermitteln und ausgeben.

Hinweis:

Der größte mögliche Wert in bash scripting ist 64 Bit signed

```
$ ((MAXINT=2**63-1))
$ echo $MAXINT
9223372036854775807
```

[min.sh](/scripts/min.sh)
```sh
#!/bin/bash

min=""

for value in $(<"$1")
do
  if [[ -z "$min" ]] || ((value < min))
  then
    min=$value
  fi
done

echo "$min"
```
- mit ``$(<"$1")`` wird der Inhalt der Datei in den stdin der Command substitution weitergeleitet und dann ins Script eingefügt.

Ausführung
```

```

```sh

sum=0
count=0

read nums

for number in $nums

  ((sum+=number))
  ((count++))
done

((average=sum/count))
```
