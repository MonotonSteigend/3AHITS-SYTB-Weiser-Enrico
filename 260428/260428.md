## Übung (Datei zu groß)



```sh
rici@envy-u:~/HTL/3AHITS/Syt-B/.../260428/scripts$ ls -l
total 8

-rw-rw-r-- 1 rici rici  23 Apr 28 08:10 test.txt
rici@envy-u:~/HTL/3AHITS/Syt-B/.../260428/scripts$ 
```
- beim fünften Feld steht die Filesize.

[filesize.sh](/scripts/filesize.sh)
```sh
FILE=$1
SIZE=$(ls -l "$FILE" | tr -s ' ' | cut -d ' ' -f 5)

test "$SIZE" -gt 100 && echo "Datei ist zu groß" || echo "Groesse OK"
```
- tr -s ' ' damit mehrere Leerzeichen zu einem werden
- cut -d ' ' setzt den divider auf ein Leerzeichen, -f 5 wählt das fünfte Feld aus.

``Ausführung``
```sh
rici@envy-u:~/HTL/3AHITS/Syt-B/.../260428/scripts$ ./filesize.sh test.txt 
Größe OK

```

## Übung (md to html)

[md_to_html.sh](/scripts/md_to_html.sh)
```sh
#!/bin/bash
SOURCE=$1
TARGET=$2

test ! -f "$TARGET" -o "$SOURCE" -nt "$TARGET" && pandoc "$SOURCE" -o "$TARGET"

```
- -nt für newer than
- -f prüft ob es sich um eine Datei handelt

## Übung (C Programm)

[diff.c](/scripts/diff.c)
```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[]) 
{

    if (argc != 3) return 1;

    int n1 = atoi(argv[1]);
    int n2 = atoi(argv[2]);

    printf("Differenz: %d\n", n1 - n2);

    return (n1 > n2) ? 0 : 1;
}

```
